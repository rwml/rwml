## 🚀 Featured Projects

### 🌐 Web & Applications

- **[Resto'N](https://github.com/rwml/RestoN)** • *Restaurant Management Platform (SAÉ)*  
  Full-featured restaurant management and ordering web application. Real-time table reservations, menu catalog, customer ordering interface, and administration dashboard.  
  🛠 Stack: **Symfony**, **PHP**, **Twig**, **Doctrine**, **MySQL**

- **Apéro Clock** • *World Clock & Blood Alcohol Simulator*  
  Interactive web application featuring a real-time world map of cocktail hours across time zones and a graphical blood alcohol concentration simulator (Widmark formula with dichotomy elimination).  
  🛠 Stack: **JavaScript (Vanilla)**, **HTML5**, **CSS3**, **OpenStreetMap** • 🔗 Live: [apero-wwat.vercel.app](https://apero-wwat.vercel.app)

- **Marvel Tracker** • *MCU Chronological Marathon Tracker (PWA)*  
  Collaborative Progressive Web App allowing multiple users to synchronize and track their real-time progression through the Marvel Cinematic Universe in chronological order.  
  🛠 Stack: **Python**, **Flask**, **PostgreSQL**, **PWA**
